<h1 align="center">Pizza Sales Analysis</h1>

<p align="center">
An interactive Power BI dashboard project analyzing pizza sales data to uncover insights about revenue, orders, categories, and pizza sizes using Excel, PostgreSQL, and Power BI.
</p>

<hr>

<h2>Project Overview</h2>

<p>
This project, <strong>Pizza Sales Analysis</strong>, provides a complete sales performance overview for a pizza business. It combines PostgreSQL, Excel, and Power BI to visualize key metrics like total revenue, order volume, best-selling pizzas, and peak sales times — helping in data-driven decision-making.
</p>

<h2>Key Features</h2>
<ul>
  <li>Total revenue, average order value, and total orders analysis</li>
  <li>Sales breakdown by pizza category (Classic, Supreme, Chicken, Veggie)</li>
  <li>Peak order hours and order distribution by days</li>
  <li>Sales percentage by pizza size (Small, Medium, Large, Jumbo)</li>
  <li>Top 5 best-selling and worst-selling pizzas</li>
  <li>Interactive visuals and filters for detailed exploration</li>
</ul>

<hr>

<h2>Technologies Used</h2>
<ul>
  <li>Microsoft Excel – for data cleaning and preparation</li>
  <li>PostgreSQL – for querying and aggregating raw sales data</li>
  <li>Power BI – for building interactive visual dashboards</li>
</ul>

<hr>

<h2>How to Use</h2>
<ol>
  <li>Open the <code>pizza_sales_excel_file.xlsx</code> dataset in Excel to review raw data.</li>
  <li>Review PostgreSQL queries in <code>SQL Queries.txt</code> used for data analysis.</li>
  <li>Open the <code>Pizza Sales Report.pbix</code> file in Power BI Desktop.</li>
  <li>Explore the dashboards using slicers and filters for deeper insights.</li>
</ol>
